项目由来

本项目最初计划作为一个 Windows 原生项目，通过“浮窗 + 灵动岛”的形式控制浏览器，从而实现辅助学习。

在后续开发过程中，作者发现浏览器插件能够更直接、更稳定地控制网页，因此改用插件方式继续制作。这也是插件命名为 WinSpeedBall 的原因。

本项目支持扩展为全自动化流程。其余功能可以通过用户脚本实现，脚本需要用户自行编写。项目公开接口、脚本编写要求及相关说明均存放在项目仓库中，完整文档为 docs/user-guide-and-script-api.md。

v3.8.5 · 长期 SDK 与完整优化2026-07-26
  • Developer SDK 运行令牌、授权会话和沙箱脚本不再按固定时间到期，用户可在主动停止前长期调用已授权接口；一次性页面确认和外部请求故障保护仍保留安全边界。
  • 长期 SDK 会话继续绑定脚本代码、能力、网站来源、标签页和图书模式；停止会话、替换或删除脚本、关闭 Developer Mode、撤销授权、页面上下文失效或浏览器会话结束时仍会清理。
  • 新增长期令牌迁移标记，升级后会清理旧版带到期时间的运行令牌与会话，不会把已经过期的旧记录恢复为长期授权。
  • 完整开放视频 all、current、status、rate、volume、mute、play、pause、auto、lock、reset 接口，并统一 Promise 错误契约。
  • 完整开放图书 status、prev、next、start、stop、interval 接口，严格隔离普通图书、图片序列和学习通图像书三种授权模式。
  • 普通图书继续使用浏览器原生按钮，图片序列继续使用浏览器原生滚动，学习通版本恢复专用 PDG/JPath 翻页机制并保留封底检测。
  • AI教学升级为独立大尺寸教学工作区，以公式、原题解析、提问和不同数据例题逐步引导；数学公式统一使用本地 MathJax SVG 清晰显示。
  • AI答题默认优先遵守用户的直接答案、格式和字数要求；结构化文本清理不再破坏 LaTeX、Markdown、JSON、表格和常用数学符号。
  • OCR 图像预处理加强浅灰色选项文字，减少 A、B、C、D 选项遗漏，并继续在本地完成识别。
  • 插件界面统一使用白色底色、黑色正文、灰色提示和淡蓝色交互色；AI教学、AI回复、脚本工作区和主界面补齐隐藏滚动条后的滚动、进度、回顶和位置记忆。
  • 普通用户脚本新增主动联网 API 防护：dom 为必需基础权限，执行环境按脚本代码和有效权限边界分离；未声明 network 时阻断直接调用 fetch、XHR 和 WebSocket，automation 只解锁受控兼容桥接。普通脚本仍可通过 DOM 触发网页资源、导航或注入主环境代码，因此不作为强沙箱。
  • 全项目审查补强长期会话撤销栅栏与失败重试、跨页面 documentId 绑定、普通脚本权限切换竞态、Sonnet 5 教学兼容和多脚本存储配额，并为 Developer SDK 沙箱增加联网封锁、原生心跳看门狗与 RPC 并发和速率保护。
  • Manifest、隐私说明、使用声明、完整脚本指南、插件内更新日志和仓库 README 全部同步到 3.8.5 Developer Beta。
v3.7.1 · 图书模式分离2026-07-17
  • “图书自动翻阅”仅识别普通网页图书阅读器，不再识别学习通或超星阅读器。
  • “图片自动翻阅”仅处理普通网页图片序列，不再调用学习通 JPath/Readweb 控制器。
  • 普通图书和图片模式不再申请学习通框架权限，学习通 PDG/JPath 功能统一保留在“学习通版本”。
  • 更新图书页面提示文字、错误信息和自动化测试，明确三个翻阅模式的适用范围。
  • 普通图书使用浏览器原生按钮点击，图片模式使用浏览器原生滚动；学习通版本继续使用独立的 PDG/JPath 专用机制。
  • Developer SDK 在保持 3.7.0-beta 版本不变的前提下补充视频与图书接口：视频新增 auto、lock、reset，图书新增 book.control 及 prev、next、start、stop、interval。
  • WSB.book.status(mode?) 现在可读取 book、image、chaoxing 三种模式；图书模式绑定本次确认与运行会话，无参调用使用会话模式，显式跨模式调用会被拒绝，默认授权模式仍为学习通以兼容原有脚本。
  • SDK 图书自动翻阅启动时先立即翻阅一次，再按间隔继续；任务按脚本、标签页和模式隔离，跨域阅读器缺少权限时提示用户先在图书面板完成检测与授权。
  • 同一 SDK 草稿重新启动会立即替换旧会话并停止旧图书任务；过期会话自动清理并设置有效会话数量上限，视频控制失败回执不再携带只读媒体字段。
  • 问题获取中的“框选识别”和“网页语音”分别更名为“文字问题”和“语音问题”，同步更新相关状态提示与操作说明。
  • “文字问题”和“语音问题”独立记住最后一次打开的标签，下次打开插件时自动恢复，不改变原有主功能页和窗口状态。
  • OCR 新增本地图像预处理：适度放大截图、将浅灰色选项文字加深、增加白色边缘留白，并使用题目块识别参数，避免遗漏灰色 A、B、C、D 选项。
  • 学习通版本恢复改动前的翻页方式：优先调用 readweb.goto，未生效时切换目标 JPath 节点并同步页码回调。
  • 左侧“AI”更名为“AI答题”；“AI教学”移动到顶部“学习助手”旁，点击后进入全页教学界面，并提供“返回正常界面”按钮。
  • AI教学新增独立的分步解题流程，可读取页面或输入题目、检查当前回答、细化当前步骤并恢复本地教学进度，不会写入AI答题历史。
  • AI教学调整为“公式解析式教学”：理科题每一步先指出当前需要的公式、定理或规律，再结合原题条件进行解析。
  • 教学按“本步公式→符号与条件→题目对应→顺带举例→回到原题”展开；没有适用公式时使用定义、定理或规律，不能编造公式。
  • AI教学、AI答题主界面和独立 AI 回复窗口中的标准 LaTeX 公式统一使用本地 MathJax 渲染为可缩放的 SVG 公式图像，兼容旧回复中的空格指数写法，不加载远程公式资源；公式已统一放大、加粗并使用纯黑字形，较长的“公式＋说明文字”会按标点和安全长度自动换行，避免整行缩小。
  • “公式与例题”按“公式提示→代入示范→完整例题”逐级增加帮助；例题必须更换数据或情境，不能代入或解答原题。
  • 完成原题后仍需独立选择并使用公式或规律通过迁移检验，正确且能说明依据后才输出最终总结；旧教学进度会自动迁移。
  • AI教学界面独立放大为 720×600 并改用左右分栏，返回正常界面后恢复 320×340；其他功能页保持原尺寸，固定独立窗口同步切换。
  • 修复从 AI教学返回正常界面后弹窗高度残留和右侧导航误展开的问题；根页面、正常布局与导航热区状态现在会同步恢复，固定窗口丢失会话编号时也能重新绑定当前窗口。
  • 分步指导新增独立滚动阅读机制：支持平滑翻屏、顶部/底部定位、键盘翻页、实时阅读进度和滚动位置记忆；新步骤到达时自动回到顶部并显示过渡效果。
  • 插件主界面、AI教学、AI回复窗口和脚本工作区统一为白色界面底色、黑色常规文字、灰色提示文字和淡蓝色交互强调。
  • 界面记忆升级为统一状态：再次点击插件图标时会恢复上次主功能页、问题获取标签、图书标签、日志标签和AI教学模式，并兼容迁移旧记录。
  • 全项目滚动机制完成统一优化：所有可见滚动条默认隐藏，但继续保留原生滚轮、触控板、触摸滑动、键盘翻页、阅读进度、位置记忆与回顶功能。
  • 修复“AI答题”的后台角色仍限制直接答题、默认模式覆盖用户要求的问题；新工作区默认进入“直接答案”模式，直接问题默认只输出最简最终答案，只有用户明确要求解析或选择解释模式时才给过程；语言、格式、字数和范围等明确要求始终优先，同时保留禁止代替用户操作或提交网页的边界。
  • AI 回复、OCR 题目和自动答题提示改用保留结构的专用文本清理流程，不再误删 LaTeX、JSON、Markdown、表格、上下标及常用数学符号。
  • 读取页面答题时会合并最多八个相关页面框架，每个框架可读取至 40000 字并优先保留含题目和选项的区域；来源仍不完整时会明确提示模型不得猜测。
  • 模型因输出上限截断回复时，主界面和独立回复窗口会显示“回复不完整/可能不完整”，正文保持原样，避免把缺失的后半部分误判为已按要求完成。
